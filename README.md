# 🚀 Selenium Automation Framework

## 📌 Overview

This project is a Selenium-based automation framework built using **Python, PyTest, and Page Object Model (POM)**. It demonstrates scalable test design, reusable components, and detailed reporting using Allure.

---

## 🛠 Tech Stack

* Python
* Selenium WebDriver
* PyTest
* Allure Reports
* WebDriver Manager

---

## 📂 Project Structure

```
selenium-automation-framework/
│
├── pages/              # Page Object classes
├── tests/              # Test cases
├── utils/              # Helper utilities
├── conftest.py         # PyTest fixtures
├── requirements.txt    # Dependencies
└── README.md
```

---

## ✅ Features

* Page Object Model (POM) design pattern
* Valid & Invalid Login Test Scenarios
* Add-to-Cart Functionality Test
* Reusable PyTest Fixtures
* Explicit Waits for stability
* Allure Reporting Integration
* Screenshot capture on test failure

---

## ▶️ How to Run the Project

### 1️⃣ Clone Repository

```
git clone git clone https://github.com/mahapatradevdeep1811-cell/selenium-automation-framework.git
cd selenium-automation-framework
```

### 2️⃣ Install Dependencies

```
pip install -r requirements.txt
```

### 3️⃣ Run Tests

```
python -m pytest --alluredir=allure-results
```

### 4️⃣ Generate Report

```
allure serve allure-results
```
