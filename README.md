# Selenium Automation Framework

## Tech Stack
- Python
- Selenium WebDriver
- PyTest
- Allure Reports

## Features
- Page Object Model (POM)
- Valid & Invalid Login Tests
- Reusable Fixtures
- Allure Reporting

## Run Tests
pip install -r requirements.txt  
python -m pytest --alluredir=allure-results  
allure serve allure-results
